# 霓虹2048

一个零依赖、单文件的 2048 数字合并小游戏，霓虹赛博风格界面，开箱即玩。

## 项目简介

霓虹2048 把经典的数字合并玩法做成一个不依赖构建工具、不依赖任何第三方库的网页应用：
整个游戏就是一份 `index.html`，双击即可运行，也可以直接丢到任意静态托管上。

界面采用深色霓虹配色，方块按数值渐变色阶区分，带有柔和的辉光和合并动效；
同时适配桌面端键盘操作与移动端滑动手势。

## 功能特性

- **完整 2048 玩法**：4×4 棋盘，同值方块相撞合并，每次有效移动后随机生成 2 或 4。
- **多端输入**：方向键、WASD，以及移动端的滑动手势；桌面端也支持鼠标拖拽。
- **撤销一步**：误操作时可以退回上一步的棋盘与分数。
- **最高分记录**：本地保存最高分，刷新页面不会丢。
- **进度自动保存**：当前棋盘和分数写入 `localStorage`，关掉浏览器再打开可以接着玩。
- **胜负状态提示**：合成 2048 时给出达成提示但不强制结束；无路可走时判定游戏结束。
- **零依赖零构建**：单个 HTML 文件，纯原生 JavaScript 实现，不需要 npm 安装或打包。

## 实现要点

棋盘状态用一个 4×4 二维数组表示。四个方向的移动统一归约为「向左压缩合并」：
向右先水平翻转，向上先转置，向下先转置再翻转，处理完再转回原方向。
这样核心的合并逻辑只需要写一份，避免四个方向各写一遍带来的不一致。

合并时每个方块一步内只参与一次合并（例如 `2 2 2 2` 一步得到 `4 4` 而不是 `8`），
这是 2048 的标准规则，也是实际实现里最容易写错的地方。
