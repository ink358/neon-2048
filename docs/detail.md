# 霓虹2048 · 作品详情

## 一、这个作品是什么

霓虹2048 是一个可以在浏览器里直接运行的 2048 数字合并游戏。整个作品只有一份 `index.html`，
没有任何第三方依赖，也不需要 npm 安装或打包构建——把它托管到任意静态服务器上就能访问，
甚至直接双击文件也能打开。

做这个作品的出发点很简单：把「经典 2048 的完整手感」和「单文件、零依赖、随时能跑」这两件事同时做到。
现在很多小游戏要么依赖一整套前端脚手架，要么为了炫效果引入了大量库，最后想分享给别人还得先教对方怎么跑起来。
霓虹2048 希望避开这一点——拿到文件就能玩。

## 二、核心功能

**完整的 2048 玩法。** 4×4 棋盘，方向键或滑动让所有方块朝同一方向移动，同值方块相撞后合并成两倍数值，
每次有效移动结束后在空格中随机生成一个 2（九成概率）或 4。棋盘填满且四个方向都无法合并时判定游戏结束。

**多端输入适配。** 桌面端支持方向键、WASD 与鼠标拖拽；移动端支持棋盘滑动手势，
滑动距离小于 24 像素视为点击而不触发移动，避免误操作。

**撤销与最高分。** 误操作时可以退回上一步的棋盘与分数；最高分写入本地存储，刷新页面不会丢失。

**进度自动保存。** 当前棋盘和分数随每次操作写入 `localStorage`，关掉浏览器再打开可以接着玩。

## 四、实现要点

**四个方向只写一份合并逻辑。** 2048 里四个方向的移动本质是同一种操作，如果每个方向各写一遍，
很容易出现某个方向漏合并或合并顺序不一致的隐藏问题。这里的做法是把所有方向先归约为「向左压缩合并」：
向右时先水平翻转棋盘，向上时先转置，向下时先转置再翻转，处理完再转回原方向。
于是核心的合并算法只需要维护一份。

**每个方块一步内只合并一次。** 这是 2048 的标准规则，也是最容易写错的地方。
一行 `2 2 2 2` 向左移动，正确结果是 `4 4` 而不是 `8`。实现上先把非零方块压紧成序列，
再从左到右扫描，相邻相等就合并成双倍并跳过下一个元素，保证刚合并出的新方块不会在同一回合里再次参与合并。

**渲染与状态分离。** 棋盘状态是一个 4×4 的二维数组，渲染函数只负责把数组映射成界面元素，
并给每个方块写上数值属性，由 CSS 按数值决定配色与字号；动画交给 CSS 完成，逻辑层不关心视觉细节。

**无路可走的判定。** 只有在空格为零时才需要检查是否存在相邻同值方块，避免了每步都做全盘扫描。

## 五、可以继续做的事

后续比较想补的是：计时模式与步数统计、可自定义的棋盘尺寸、以及把最高分同步到云端做成多端排行榜。
这些都是在这个单文件结构上可以逐步加出来的，不会破坏「零依赖、开箱即玩」的前提。
